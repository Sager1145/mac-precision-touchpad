Magic Trackpad 3 USB-C and Bluetooth - test-signed preview

This package is signed with a local WDK test certificate. It is not Microsoft/WHQL production-signed. Windows must already be configured to allow test-signed drivers; Setup checks the active policy and stops if it is not enabled.

Setup does not change boot configuration, Secure Boot, BitLocker or Memory Integrity. Read INSTALL.txt for preparation instructions. Certificate trust is a separate, optional task on the next page. Select it only if you want to trust this bundled public test certificate. No private key is distributed.

Setup installs matching Apple trackpad devices, backs up previous packages and creates an entry in Windows Installed apps. Connect USB-C or pair the trackpad in Windows Bluetooth settings. Unplug USB to test Bluetooth input.

Pointing, dragging, scrolling, flick momentum and reconnects were tested on Magic Trackpad 3 USB-C. Other bundled MacBook drivers retain upstream support but have not been hardware-tested for this release.

Uninstall removes only packages recorded by this installer. It retains driver backups, logs and certificate trust for recovery. It does not remove unrelated driver packages or change Windows boot settings.
