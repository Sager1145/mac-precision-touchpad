# v0.1.0-preview.1 - smoother Magic Trackpad USB resampling

**Windows x64 test-signed prerelease. Not Microsoft/WHQL production-signed.**
See the [test-signed installation instructions](../test-signed-installation.md).

Continuous pointing, click-dragging, and two-finger scrolling now use an 8 ms
high-resolution waitable timer. An eight-sample history interpolates measured
positions with a fixed 12 ms buffer instead of alternating raw reports and
prediction corrections. Position is not low-pass filtered. Bounded prediction
remains available when a target is newer than the physical samples.

Touch-down, button changes, and lift-off remain immediate. Advancing ScanTime,
one-shot releases at the last delivered coordinates, and the working flick
momentum behavior are preserved. The timer worker is joined and handles are
closed at power exit; a WDF timer fallback preserves operation on systems
without high-resolution waitable timers.

Validation:

- Release x64 build: zero warnings and errors (Enterprise WDK 28000).
- Interpolation, contact lifetime, click-drag, two-finger movement, native
  timer lifecycle, and timer-start fallback regression checks pass.
- Magic Trackpad 3 USB-C installed with Status=OK, ProblemCode=0.
- In a 45-second capture: 8.1563 ms median continuous spacing, 8.5543 ms at
  the 95th percentile; no sub-millisecond continuous report pairs, duplicate
  timestamps, missing releases, invalid release coordinates, or unavailable reads.
- User confirmed smoother movement and preserved flick momentum.

Windows scheduling is not hard real-time; nine of 1094 continuous intervals
exceeded 12 ms. The build uses the existing SkipPackageVerification option
and has not undergone WHQL/compliance certification. The 12 ms buffer adds
a fixed motion latency. Hardware validation covers USB-C Magic Trackpad 3;
other models/transports are not newly validated by this release.

Release assets include the signed driver package ZIP, the public test
certificate, SHA-256 checksums, and release notes. No private signing key is
distributed. The manifest in the ZIP records its source commit and driver version.
