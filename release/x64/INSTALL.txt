Mac Precision Touchpad — prebuilt x64 driver (v0.2.0-preview.1)

This folder is the compiled driver package, checked in so it can be installed
without building. Installation follows the upstream imbushuo/mac-precision-
touchpad method: right-click the INF and install. Upstream's unsigned CI
builds (after 2021/01/06) used the same method and additionally required
test-signing mode; the note below applies to this fork's test-signed build.

Files
  AmtPtpDevice.inf        primary driver package INF (right-click to install)
  amtptpdevice.cat        signed catalog for the USB/SPI/Bluetooth package
  AmtPtpDeviceUsbUm.dll   user-mode USB driver (UMDF)
  AmtPtpHidFilter.sys     HID filter driver (KMDF, Bluetooth filter)
  AmtPtpDeviceUsbKm.sys   kernel-mode USB driver (KMDF)
  AmtPtpDeviceSpiKm.sys   kernel-mode SPI driver (KMDF)
  AmtPtpHidFilter.inf     standalone Bluetooth filter INF
  amtptphidfilter.cat     signed catalog for the Bluetooth filter
  AmtPtpDeviceTest.cer    public WDK test certificate (no private key)
  manifest.json           per-file SHA-256 hashes and source commit

This build is TEST-SIGNED (WDK test certificate), not Microsoft/WHQL
production-signed. Windows x64 requires preparation first:

  1. Disable Secure Boot in UEFI/BIOS firmware settings.
  2. Enable test-signing mode (Administrator Command Prompt):
        bcdedit /set testsigning on
  3. Reboot. A "Test Mode" watermark appears in the bottom-right corner.
  4. Trust the test certificate (Administrator PowerShell):
        certutil -addstore Root .\AmtPtpDeviceTest.cer
        certutil -addstore TrustedPublisher .\AmtPtpDeviceTest.cer
  5. Right-click AmtPtpDevice.inf and select "Install",
     or (Administrator PowerShell):
        pnputil /add-driver .\AmtPtpDevice.inf /install
  6. Connect the trackpad over USB-C, or pair it in Bluetooth settings.
     Unplug USB when testing Bluetooth.

catalog membership. See docs/test-signed-installation.md for full details and
